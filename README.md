# ECHO - Community Discussion Platform

![PHP](https://img.shields.io/badge/PHP-777BB4?style=for-the-badge&logo=php&logoColor=white)
![CSS](https://img.shields.io/badge/CSS-1572B6?style=for-the-badge&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black)

**ECHO** is a lightweight, MVC-based community discussion platform built with **PHP**. It allows users to create, read, and engage in discussions — similar to a simple forum or Reddit-style community board.

## ✨ Features

*(Copy the content from your `FEATURES.md` here or summarize the key features below)*

- User authentication and registration
- Create and browse discussion threads/topics
- Post replies and engage in conversations
- Clean and responsive UI
- MVC (Model-View-Controller) architecture for better maintainability
- Easy to extend and customize

> For the complete list of features, see **[FEATURES.md](FEATURES.md)**.

## 🛠 Tech Stack

- **Backend**: PHP (MVC pattern)
- **Frontend**: HTML, CSS, JavaScript
- **Architecture**: Model-View-Controller

text## 🚀 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/ECHO.git
   cd ECHO

Set up your web server (Apache/Nginx) and point the document root to the project folder.
Configure your database:
Create a new MySQL/MariaDB database
Import any provided SQL schema (if available in the repo)
Update database credentials in the configuration file (usually inside model/ or a config.php file)

Make sure the controller/, model/, and view/ folders have proper read/write permissions where needed.
Open the project in your browser and start using ECHO!
